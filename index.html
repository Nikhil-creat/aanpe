Architecture

From pixels to a drive decision.

1. Sanitise

Shape, channel and range checks, plus a smoothing residual to flag sensor noise or adversarial perturbation.

2. Segment

DeepLabV3+ with a ConvNeXt encoder. Labels 255 (rover, range over 30 m) are ignored in loss and metrics.

3. Judge

Safety Critic reads class areas and entropy, then triggers retrieval over historical rover anomaly records.

4. Decide

Path agent proposes a steering change, or the fail-safe forces a halt when entropy or latency limits break.

Evaluation protocol

Measured, not claimed.

Benchmarks

Expert sets test_min1 and test_min3, scored against a baseline that predicts soil for every pixel.

Metrics

Exact confusion matrix, pixel accuracy, per-class IoU and mean IoU, with label 255 excluded.

Failure analysis

Sand predicted as soil or bedrock is extracted and saved to an inspection folder for review.

No scores are published here until you train and run engine/evaluate.py yourself.

Deploy

Edge-ready container.

docker build -t aanpe . && docker run --gpus all -p 7860:7860 aanpe

FAQ

Why halt instead of guessing?

A wrong drive on sand can end a mission. Uncertain pixels become Restricted Hazard.

Does the site run the model?

No. The site is static; the model runs from the Python engine. The chatbot only talks to Groq or Gemini.
